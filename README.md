## 🧭 Sobre o projeto

Este repositório reúne o progresso nos fundamentos do desenvolvimento web, com exemplos práticos de **HTML5**, **CSS3** e primeiros exercícios com **PHP**. O conteúdo foi organizado a partir de atividades de aula, testes de estrutura e experimentos para entender como uma página é construída.

A coleção funciona como um laboratório de aprendizagem: cada arquivo explora uma tag, um componente, uma técnica de estilização ou uma interação diferente.

## 🛠️ Como visualizar

### Arquivos HTML

1. Baixe ou clone o repositório.
2. Entre na pasta `APRENDENDO HTML-CSS-PHP 🤔`.
3. Abra qualquer arquivo `.html` no navegador.
4. Para estudar a estrutura, abra o mesmo arquivo no VS Code ou em outro editor.

```bash
git clone https://github.com/jcauan374-ads/Logicas-Em-Html.git
cd Logicas-Em-Html
```

### Arquivos PHP

Para visualizar arquivos PHP, é necessário utilizar um servidor local, como o servidor embutido do PHP:

```bash
php -S localhost:8000
```

Depois, acesse `http://localhost:8000` no navegador.
